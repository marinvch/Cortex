# notes/ — the knowledge graph

Permanent, atomic notes. One idea per file, written in your own words, `[[wikilinked]]` to the
notes it relates to. This is the layer that compounds — everything else is scaffolding around it.

Start from `templates/note.md`. Notes arrive here by promotion, not by capture: `/weekly-review`
pulls what's worth keeping out of `inbox/`, and `/reindex` nominates the topics that have grown
dense enough to deserve a Map of Content (`templates/moc.md`).

> Only this README is committed. Your notes are gitignored and stay on your machine.
