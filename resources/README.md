# resources/ — topic reference material

Reference you collect because a topic interests you, not because a project needs it right now:
clippings, docs, research, examples.

Keep it shallow. When a resource becomes something you actually *think* with, rewrite it as an
atomic `[[wikilinked]]` note in `notes/` — resources are raw material, notes are knowledge.

> Only this README is committed. Your resources are gitignored and stay on your machine.
