# projects/ — outcome + deadline

One file (or folder) per project, personal or business. A project has a **finish line**: an
outcome you can point at and a rough date. When it has neither, it belongs in `areas/`.

Start from `templates/project.md`. `/weekly-review` updates status here; `/level-up` looks here
for leverage. Codebases registered with `cortex-init.sh --register-to-vault` land here as
metadata-only stubs (name, path, stack — never code).

> Only this README is committed. Your projects are gitignored and stay on your machine.
