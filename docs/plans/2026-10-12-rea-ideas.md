# Plan: four ideas taken from `morluto/rea`

Specs: [the rule ledger](../specs/2026-10-12-rule-ledger-design.md) ·
[checking another agent](../specs/2026-10-12-other-agent-check-design.md)

Four ideas were read out of `rea` on 2026-10-12. This plan says what happens to each. Two are
built, one is already true of Cortex, and one waits.

**Rules for every step:**
- One PR per step against `master`, merged before the next step starts. Never stacked.
- Tests are written first.
- Every step runs `node --test core/test/*.test.js`, `node --test index/test/*.test.mjs`,
  `npm test` in `mcp/`, `node --test evals/test/*.test.mjs`, `node evals/run.mjs --check` and
  `bash tools/test/run.sh`.
- Versions are stamped with `node tools/cortex-version.mjs --set`, and a stamped merge is a
  release (ADR 0022).
- No step starts a model session.

## Graded claims

Read against the code on 2026-10-12, Cortex already keeps this discipline:

- Languages whose imports it cannot resolve are left out of the unreferenced list and named in the
  report as a blind spot (`UNRESOLVED_LANGUAGES`, `lib/imports.mjs`; `findings.mjs`).
- Every dependent count is a floor and its field is `atLeast` (`lib/impact.mjs`).
- Coverage says a file "appears untested", and `lib/coverage.mjs` states it reports a floor.
- The unreferenced finding can only remove entries (`lib/orphans.mjs`).

| # | Step | Files | Verified by |
|---|---|---|---|
| G1 | A file the text source could not read is counted where the report is printed. `namedElsewhere` skips an unread file silently, so a candidate named only by an unread file is listed as unreferenced with nothing said. The unreferenced finding states how many indexed files were not read, when that number is above zero | `index/lib/findings.mjs`, `index/test/findings.test.mjs` | A source with one unreadable file that names the only candidate: the finding still lists the candidate and its text carries the count; with nothing unread the text is byte-for-byte what it is today |

G1 changes a finding's text and not its rank, so the install interview does not move (ADR 0006).
It starts by confirming on a fixture that the count is not already printed elsewhere in the
report; if it is, the step is dropped and that is written here.
