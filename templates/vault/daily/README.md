# daily/ — one note per day

`YYYY-MM-DD.md`, created by `/daily` from `templates/daily.md`. Part log, part journal: what's on
today, what happened, what's still open. The cheapest place to put a thought when you don't yet
know where it belongs.

Daily notes are a holding pen, not an archive. `/weekly-review` reads back over the week and
promotes anything durable into `notes/`, `projects/`, or `areas/`; unchecked `- [ ]` items roll
forward into tomorrow's note.

> Only this README is committed. Your daily notes are gitignored and stay on your machine.
