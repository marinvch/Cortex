# inbox/ — the capture zone

Everything lands here first. Speed over structure: `/capture` drops a thought here (or into
today's daily note) without asking where it belongs.

Nothing in this folder is permanent. `/weekly-review` empties it — promoting what's worth keeping
into `notes/`, `projects/`, or `areas/`, and deleting the rest.

> Only this README is committed. Your captures are gitignored and stay on your machine.
